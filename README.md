# CogniPulse AI

CogniPulse AI is an AI-assisted productivity, stress, and wellness monitoring platform.

## Project Structure

- `frontend/` — React frontend
- `backend/` — FastAPI backend
- `ml/` — Machine learning pipeline
- `docs/` — Project documentation
- `docker/` — Docker configuration

## Tech Stack

- React + Vite
- Tailwind CSS
- FastAPI
- MySQL
- SQLAlchemy
- Python
- Scikit-learn
- Docker
- Git
